# 简历批量投递助手

一个跑在**你自己电脑上**的简历批量投递工具。

你平时在邮箱里投简历：填收件人、写主题、写正文、拖简历附件、点发送，一家公司来一遍。
这个工具把这些重复动作替你做：**你写好一封「通用邮件」，它自动发给几十家公司，
每封里的公司名、岗位名自动换成对应的，简历附件自动带上。**

不联网、不上传、不需要注册。所有数据只存在你自己电脑的 `data/` 和 `attachments/` 文件夹里。

---

## 功能

- **投递清单**：手动添加、在线填表、Excel 批量导入、导出投递记录；按状态 / 进展 / 标签 / 投递日期区间筛选。
  公司、岗位、邮箱、备注**点一下就能直接改**（回车保存，Esc 放弃），不用开弹窗
- **在线填表**：不想开 Excel 就在网页里直接填（表格式，支持从 Excel 整块复制粘贴、也可以直接拖个 `.xlsx` 进来铺好）。
  填完用鼠标**框选**要导入的那块区域，确认「第几列是什么」之后再导 —— 只导你框的那部分，不是全表无脑导
- **标签**：给清单条目打标签（比如「9/19晚投」「国企」），一条可以打好几个。
  导入时可以顺手给整批打上，之后按标签筛选、点标签看同一批，公司多了也不会乱。
  一条最多 12 个；超出会明确告诉你被挤掉几个（不会默默丢掉）。
  清单里一条只直接显示 2 个标签，多的折成「＋N」，点开能看全
- **投递记录**：单独一页。每发一封留一条 —— 什么时候发的、发给谁、成没成、失败是什么原因；
  可搜公司或邮箱，可只看成功 / 只看失败，也可按日期区间筛
- **邮件模板**：主题和正文里可以用 `{公司}`、`{岗位}`、`{姓名}` 等占位词，发送时自动替换成真实内容
- **多套话术（投递定位）**：可以同时存好几套模板，各自起名（比如「AI岗」「专业对口」）。
  清单里每条用「投递定位」那一列挑一套 —— 投 AI 岗用一套说法、投专业对口岗用另一套说法，互不干扰。
  每套可以单独编辑、改名、设为默认、删除；某家公司还要更特殊，再单独定制它一个
- **单独定制**：某家公司要求不一样时（比如要压缩包、主题要按它的格式写），可以只改这一家的主题/正文/附件，不影响其他公司
- **附件库**：统一管理简历、成绩单、压缩包；每个附件可以写一句只给自己看的备注，方便区分文件
- **附件在线预览**：凡是出现附件的地方都能点「预览」，直接用浏览器打开看 ——
  PDF 带缩放、翻页、搜索、另存，图片直接显示，不用先下载再找软件打开
- **材料合并**：把学籍证明、成绩排名、证书之类的材料合成一个 PDF —— 一封邮件只挂两个附件，HR 不用下一堆文件
- **批量发送**：QQ 邮箱 SMTP，支持发送间隔、每日上限、失败记录、中途停止、实时日志、进度条
- **求职进展跟踪**：未回音 / 笔试 / 面试 / Offer / 挂了 / 我放弃 六种状态，重要日期到期提醒，随手记笔记
- **整封邮件预览**：发送前能直接看到 HR 收到的样子，挂的附件也能点开看

## 环境要求

- **Windows**（启动脚本是 `.bat`；其它系统直接 `python app.py` 也能跑）
- **Python 3.10 或更高**

安装依赖：

```bash
pip install openpyxl pypdf pillow
```

| 依赖 | 用来干嘛 | 不装行不行 |
|---|---|---|
| `openpyxl` | 导入 / 导出 Excel | **必须装** |
| `pypdf` | 合并 PDF | 不用材料合并就不用装 |
| `pillow` | 处理证书照片（摆正、缩放） | 同上 |
| `tkinter` | 独立合并工具窗口 | Python 自带，不用额外装 |

## 启动

1. 装好依赖
2. 双击 `Start.bat`，或者命令行跑 `python app.py`
3. 浏览器会自动打开 `http://127.0.0.1:8765`
   （8765 被占用的话会自动往后试 8766 / 8767 / 8768）
4. **关掉那个黑色窗口就是退出软件**

> **同时只能开一个。** 黑色窗口还开着的时候再双击一次 `Start.bat`，它不会开第二个软件，
> 只会把已经开着的那个页面再给你打开一次。
> （这一点很重要：开两个会共用同一份数据，互相覆盖，而且同一批邮件可能被发两遍。）

## 第一次使用

**第 1 步：拿 QQ 邮箱授权码**（唯一有点麻烦的一步）

授权码是什么：QQ 邮箱不允许外部软件用你的 QQ 密码发信，所以要单独开通「软件发信权限」，
开通后邮箱会给你一串 16 位字母，这串就是授权码。

1. 电脑浏览器打开 `mail.qq.com`，用手机 QQ 扫码登录
2. 页面最上方点「设置」→ 再点「账号」
3. 一直往下拉，找到标题带 **POP3 / IMAP / SMTP** 的那个板块
4. 点「POP3/SMTP 服务」右边的「开启」→ 弹窗里点「生成授权码」→ 按提示用手机发一条短信
5. 页面会出现一串 **16 位字母** —— 立刻复制保存，**它只显示这一次**
   （真忘了也没事：把开关关掉重新开一次，会生成新的）

**第 2 步：填进软件**

打开「发送设置」标签页，填写：QQ 邮箱地址、授权码、发件人显示名、你的姓名 / 学校 / 专业。点「保存设置」。

**第 3 步：上传简历**

还在「发送设置」，往下找到「简历附件」，选择简历 PDF 上传。

**第 4 步：写一封通用邮件**

打开「邮件模板」标签页，写主题和正文。可用的变量：

| 变量 | 发送时替换成 |
|---|---|
| `{公司}` | 这家公司的名称 |
| `{岗位}` | 这一条的岗位名称 |
| `{姓名}` | 你在设置里填的姓名 |
| `{学校}` | 你在设置里填的学校 |
| `{专业}` | 你在设置里填的专业 |
| `{备注}` | 这一条的备注 |

右侧「整封邮件预览」能直接看到 HR 收到的效果。改完点「保存这套」。

**想投两类岗位、各用一套说法？**

「邮件模板」页左上角可以存好几套话术：

1. 点「＋ 新建一套」→ 起个名字（比如 `AI岗`）→ 把正文写进去 → 点「保存这套」
2. 回到「投递清单」，每一行都有一列叫「**投递定位**」，下拉挑一套
3. 不想逐条挑的，就在「邮件模板」页选中某套，点「★ 设为默认」——
   以后新加的清单默认就用它，标着「默认」的行会跟着默认那套走

发送时会按每条自己的投递定位取话术，日志里也会写清楚这封用的是哪套，方便回头查。

**第 5 步：加公司然后发送**

「投递清单」里加公司，有三条路，随便挑：

- **手动加**：「＋ 添加投递目标」，一次填一家
- **在线填表**（推荐）：点「📝 在线填表」，在网页的表格里一行填一家；
  Excel 里已经有的，直接复制那一片粘进来就行。填完**用鼠标框选**要导的那几列几行，点「导入选中区域」——
  导入前会弹个确认框，把「第1列=公司、第2列=岗位、第3列=收件邮箱」列给你看，你点头才写入
- **Excel 导入**：点「⬇ 下载清单模板」，用 Excel 一行填一家 → 保存 → 回软件点「📂 导入 Excel」

填完之后勾选要投的公司 → 点「开始投递」→ 确认。软件会自动一封封发过去，下方有实时进度和日志。

> **列的顺序（在线填表 / 按列导入）**：从左到右固定是 **公司 / 岗位 / 收件邮箱 / 备注**。
> 备注可以空着，只填前三列也行；表头行（写着「公司 岗位 邮箱」那种）会自动跳过。

## 材料合并：为什么值得用

证明材料一多（学籍证明、成绩排名、证书、推荐表……），邮件里挂七八个附件，
HR 要下七八次、开七八个文件，看着就烦、还容易漏看。

做法：**简历单独一份 PDF，其余材料全部合成一份 PDF。** 一封邮件只挂两个附件。

打开「材料合并」标签页，两种方式：

- **打开合并工具（独立窗口）**：功能最全 —— 每一页都能预览、单张能旋转、能逐张改页面大小和缩放方式。保存时默认落在附件库。
- **在网页里直接合成**：懒人版，加文件、用 ↑↓ 排顺序、点合成。适合不用调方向和页面大小的场合。

顺便还解决一个问题：手机拍一张证书 3~5 MB，十张就 40 MB 以上，邮件根本发不出去。
合并时会自动把照片按自带的旋转信息摆正、按 A4 铺好、压到 144 dpi，10 页大约 2~3 MB。

> 注意：合并时图片会被重新压缩，但 **PDF 是原样搬过去的、不做二次压缩**。
> 如果你塞进一个 20 MB 的扫描件 PDF，合出来还是 20 MB，得先自己压一下。

## 数据与隐私

- 所有数据只在你本机：
  - `data/` —— 配置、投递清单、发送记录、附件备注、邮件话术（`templates.json`）
  - `attachments/` —— 附件库（简历、证明材料等）
- 授权码以**明文**保存在 `data/config.json` 里 —— 它的作用等同于你邮箱的发信权限，别把这个文件发给别人
- 软件**不连接任何第三方服务器**，只连接 QQ 邮箱的发送服务器（`smtp.qq.com:465`）
- `data/`、`attachments/`、`_server_log.txt`、`data/local_python.txt` 都已加进 `.gitignore`，不会被提交

## 注意事项

- **发送节奏**：默认每封间隔 40 秒、每天最多 50 封，**别再改快了**。
  间隔最少只能填 20 秒（软件拦着），但 20 秒已经在风险线上，30 秒以上才稳。
  一天 50～100 封是安全区；100 封以上随时可能被限。详见下面「为什么不能发太快」
- **被限流**：如果某天突然全部失败、提示「登录失败」，多半是邮箱临时限制了，等 1~2 小时再发
- **附件大小**：上传单个附件上限 15 MB。材料合并时单个来源文件上限 30 MB，
  合并结果如果超过 15 MB 界面会提醒你 —— 邮件一般也塞不下太胖的附件
- **发之前会自动检查附件**：如果某家公司勾的附件在附件库里找不到了、或者附件库整个是空的，
  软件会**先拦下来、一封都不发**，并告诉你是哪几家出了问题。
  这时补上附件就行；也可以选"只投其余能发的"，那一批里有问题的会被标成「失败」并写明原因。
  （以前这种情况会悄悄发出一封没带简历的邮件，状态还显示"已发送"，根本看不出来。）
- **请只向你确实要投递的公司发送**，不要用它群发广告或骚扰信息
- **授权码别告诉任何人**：有了它就能用你的邮箱发信
- 批量发送前建议先给自己发一封试试效果（收件人填自己的邮箱）

## 为什么不能发太快（重要，别跳过）

**邮箱看不懂你在投简历。** 它看不到你的诚意，只看"行为长什么样"：

> 一个账号 + 短时间内 + 发给一堆互不相识的收件人 + 内容高度相似 + 带附件

—— 这正好是垃圾邮件的标准画像。**投简历和打广告，在邮箱眼里长得一模一样。**

腾讯自己的帮助页里就写着"访问频率过高会限制服务"，只是没把确切数字贴在墙上
（网上流传的口径 100 / 200 / 500 封都有，说明是按账号动态判断的）。
所以别把它当"官方没说就没事"——是**动态风控，不公开线在哪**。

**一秒一封是什么概念：** 一小时 3600 封。这不是"会不会被发现"的问题，
是这个节奏在头几封之后就会被拦下来。

被拦之后，后果分三档（从轻到重）：

| 情况 | 表现 | 恢复 |
|---|---|---|
| 临时限流（最常见） | 之后全部失败、提示「登录失败」 | 等 1~2 小时 |
| 授权码作废 | 突然报 `535 Login Fail` | 重新生成授权码，可能要等一天 |
| 服务被停用 | SMTP 服务被关 | 要重新开通，最麻烦 |

> 不是吓唬：公开有人反馈过"一连发 9 封，之后授权码就失效了"。

**还有一笔更常见的隐形损失：HR 那边压根收不到。**
你清单里的收件人很多是 163、企业邮箱，它们对"陌生发件人 + 短时间大量 + 带附件"判得更狠，
会直接把邮件丢进垃圾箱或者拒收。你这边显示"发送成功"，人家那边什么也没看见 ——
**比被限流更常见，而且你完全察觉不到。**

**所以这个软件为什么默认 40 秒一封、一天 50 封：** 这是刻意压到很低的，
不是随便定的数。间隔最少只能填 20 秒（填更小会被自动改回 20），
但 20 秒已经在风险线上，**30 秒以上才稳**。

真想多投几十家，正确做法是**分几天投**（每天 50 封已经很够了），
而不是把间隔改小 —— 后者只会让你在第二天连正常邮件都发不出去。

## 常见问题

**提示「登录失败」？**
十有八九是授权码填错了（它是 16 位字母，不是 QQ 密码）；也可能是邮箱没开通服务，重做「第一次使用」的第 1 步。

**授权码忘了 / 当时没保存？**
回到邮箱设置页，把原来的开关「关闭」再「开启」，会生成新授权码。

**一批全部发送失败？**
邮箱可能临时限流。等 1~2 小时，在清单里点「把失败/已发送重置为待发」，再投一次失败的。

**HR 的回复去哪看？**
你的 QQ 邮箱收件箱（也翻翻垃圾箱），建议每天看一次。

**正文能加粗、改颜色吗？**
软件发的是纯文本，求职邮件这样最稳妥：任何设备上显示一致、最不像广告邮件。

**网页上点了按钮没反应？**
先看看启动时那个黑色窗口还在不在。不在就是软件已经退出了，重新双击 `Start.bat` 即可。

**导入 Excel 时说这是老格式 / 报一堆英文？**
这个软件只认 **.xlsx**（新版 Excel）。老版的 **.xls** 读不了 ——
在 Excel 里点「文件 → 另存为」，格式选 `.xlsx`，存一份再导新的那个。
（以前碰到 .xls 会弹一句英文 `File is not a zip file`，现在会直接告诉你怎么做。）

**在「在线填表」里打开 Excel，为什么只铺进来一部分？**
那张表格最多放 **400 行**，超出的部分铺不进来 —— 现在会明确弹窗告诉你少了多少。
公司超过 400 家的话，别用在线填表，直接在「投递清单」页点「📂 导入 Excel」，
那条路**没有行数上限**。

**点「开始投递」弹出来说附件有问题？**
说明有几家公司勾的附件被删掉或改过名字（重新上传同名文件会变成 `xxx(1).pdf`，名字就对不上了）。
到「发送设置」看附件库，或在清单里点那家公司的「编辑」重新勾选附件。
软件之所以要拦：宁可不发，也不发一封没带简历的邮件。

**投递过程中我还能改清单吗？**
可以。改进展、写备注、打标签、改邮箱、删条目、加新公司都没问题，
改动不会被后台发信覆盖，删掉的那些也不会再发出去。
（正在发的那一封已经出去了，改它不回头生效。）

**软件提示"内容读不出来、已备份"是什么意思？**
某个数据文件坏了（断电、磁盘故障之类）。软件**不会**直接覆盖它，
而是原样改名备份成 `xxx.json.corrupt-日期时间` 放在 `data/` 里，页面顶部也会提醒你。
想恢复：把那个备份文件改回原名（比如 `jobs.json`），再重启软件。
